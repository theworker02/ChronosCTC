## Before filing an issue

Please include:

- Cronos-CTC version / git commit (`git rev-parse --short HEAD`)
- Rustc version (`rustc -V`)
- OS and architecture
- Minimal reproduction (`cargo run -p ctc-cli` snippet or failing test)
- Relevant `configs/runtime.toml` excerpts (redact secrets)

## Response expectations

This is a maintainer-driven open-source project. Best-effort replies; no SLA.
