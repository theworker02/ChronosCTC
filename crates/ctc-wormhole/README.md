# ctc-wormhole

Inter-continuum wormhole portals — synthetic in-memory bridges that tunnel
`TemporalPacket` payloads across federated chronal regions.

## API

- `WormholePortal` — bidirectional portal between two continuum endpoints
- `WormholePacket` — stamped payload envelope for portal transit
- `open_portal` / `transmit` / `receive` — lifecycle helpers
